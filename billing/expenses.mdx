### Receipt Scanning with Every Agent AI

Every's AI-powered receipt scanner automatically extracts expense details from photos and PDFs, eliminating manual data entry.

#### How Receipt OCR Works

**Step-by-step:**
1. Take a photo of your receipt or have a PDF ready
2. Go to [**Expenses**](https://app.every.ai/expenses) → **Add Expense** OR ask Every Agent "Log this receipt"
3. Upload the image/PDF (drag & drop or click to browse)
4. Every Agent's AI analyzes the receipt and extracts:
   - **Merchant name** (business name)
   - **Total amount** (final charged amount)
   - **Date** (transaction date)
   - **Category** (expense type based on merchant)
   - **Payment method** (if visible: card, cash, check)
5. Review the extracted data in the form
6. Correct any inaccuracies
7. Add optional details (client for billback, notes)
8. Save expense

**Supported in the expense form:** JPEG, PNG, GIF, WEBP, PDF, and CSV
**File size limit:** Up to 5MB per file

#### What AI Can Extract

Depending on the receipt, Every can extract the merchant, final amount, transaction date, currency, tax amount, description, and a suggested category. The form shows a confidence warning when the file may not be a receipt or the reading is uncertain.

**Tips for best results:**
- Use clear, well-lit photos
- Capture entire receipt (top to bottom)
- Avoid shadows and glare
- Ensure text is readable
- Flatten crumpled receipts before photographing

<Note>
  Always review Every Agent-extracted data before saving. The AI is highly accurate but not perfect, especially for handwritten receipts or faded text.
</Note>

#### Common OCR Issues & Fixes

**Issue: Wrong amount extracted**
- **Cause:** AI read subtotal or tax line instead of total
- **Fix:** Always verify total is correct, adjust manually if needed

**Issue: Date is incorrect**
- **Cause:** Receipt has multiple dates (printed date vs transaction date)
- **Fix:** Check transaction date on credit card statement if unclear

**Issue: Category is wrong**
- **Cause:** Merchant doesn't clearly indicate business type
- **Fix:** Manually select the correct category. You can also create consistent vendor rules for recurring merchants.

**Issue: Merchant name truncated**
- **Cause:** Receipt shows abbreviated name
- **Fix:** Edit to full business name for better record-keeping

**Issue: Receipt unreadable**
- **Cause:** Poor photo quality, faded thermal receipt, crumpled paper
- **Fix:** Re-photograph in better lighting, or enter data manually

## Billable Expenses

Bill expenses back to clients by marking them billable and adding to invoices.

### Marking as Billable

**When creating:** Add expense → Check "Billable to Client" → Select client → Save
**Existing expense:** Edit expense → Check "Billable to Client" → Select client → Save

Billable expenses show client name, "Unbilled" status until invoiced, and can be filtered by billable status.

<Tip>
  **Ask Every Agent:** Mark expenses billable:
  - "Make my last 3 expenses billable to Client XYZ"
  - "Set this travel expense as billable to the website project client"
  - "Which expenses are unbilled for ACME Corp?"
</Tip>

### Adding to Invoices

**Process:** Create invoice → Select client → Click "Add from Expenses" → Select unbilled expenses → Add Selected → Expenses become line items with description and amount → Marked as "Billed"

**Example:**
```
Expense: Client meeting travel, $145.50, Category: Travel

Becomes Invoice Line Item:
  Description: Client meeting travel
  Amount: $145.50
  Quantity: 1
```

**Markup:** Set a percentage markup on a billable expense. When it becomes an invoice line item, Every applies that percentage to the expense amount.

<Tip>
  Clearly communicate your expense policy with clients upfront. Some expect expenses at cost, others accept markup.
</Tip>

<Tip>
  **Ask Every Agent:** Add expenses to invoices:
  - "Create an invoice with Client XYZ's unbilled expenses"
  - "Add this travel expense to ACME's current invoice"
  - "Bill all expenses from last month to Client ABC"
</Tip>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can Every read a receipt for me?">
    Yes. Upload a supported image, PDF, or CSV in the expense form, or attach receipt files in Every Agent. Review the merchant, date, amount, currency, tax, and category before saving; receipt extraction is not guaranteed to be correct.
  </Accordion>

  <Accordion title="How do I bill an expense to a client?">
    Mark the expense as billable, choose the client, and optionally set a percentage markup. On that client's draft invoice, add the unbilled expense as a line item.
  </Accordion>

  <Accordion title="Can I delete an expense after it is invoiced?">
    Not while an invoice line item still references it. Remove it from a draft invoice first. For an issued invoice, preserve the billed record and correct the client document through the appropriate invoice workflow.
  </Accordion>

  <Accordion title="Does Every decide whether an expense is tax-deductible?">
    No. Categories and exports help organize records, but deductibility and documentation rules depend on your jurisdiction and circumstances. Confirm them with your accountant or tax authority.
  </Accordion>
</AccordionGroup>

## Troubleshooting

**Receipt upload failed:** Check file size (under 5MB), format (JPEG, PNG, GIF, WEBP, PDF, CSV), internet connection, browser file upload permissions. Compress large images if needed.

**Every Agent extracted wrong amount:** Common issue is reading tax/subtotal instead of total. Always review extracted data and correct before saving.

**Billed expense differs from invoice:** Check the source expense and its saved invoice line item. Correct the relevant record and review the client document before resending.

**Expense not in "Add to Invoice":** Verify expense is marked billable, assigned to correct client, not already billed, and exists (not deleted).
