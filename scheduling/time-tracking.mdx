## Overview

Every's timesheet connects work performed to the client, service, and invoice that bills it. Use the live timer while you work, add an entry after the fact, or ask Every Agent to log completed time from a plain-language description.

<Card title="Open Timesheet" icon="clock" href="https://app.every.ai/timesheet" horizontal>
  Track and review client time
</Card>

## Use the live timer

Open the timer widget, choose a client, optionally choose a service, add a description, and start the timer. You can pause, resume, collapse, or hide it while you move through the app.

The active timer is saved in the browser for the current organization, so hiding the widget or reloading the page does not silently discard an in-progress session. Choose **Stop and save** when the work is complete.

<Note>
  The timer requires a client before it can save. Add a service when you want the entry to carry that service's billing rate into an invoice.
</Note>

## Add time manually

Go to [**Timesheet**](https://app.every.ai/timesheet) → **Add Time** and enter:

- Date, start time, and end time
- Client, when the work belongs to a client
- Service, when the work should use a saved service and rate
- A client-facing description
- Optional private notes for Every Agent

You can also ask Every Agent to create a completed entry:

```text
Log 90 minutes for ACME today for the strategy workshop service.
Add a time entry from 1:00 to 3:30 yesterday for the Northwind design review.
Show me unbilled time for ACME this month.
```

Every Agent creates a time record; it does not control the live browser timer.

## Rates and billable time

Time entries use the rate on the linked service. The invoice quantity comes from the entry duration, and the rate comes from that service when you add the time to an invoice.

- A client plus a service makes the entry ready for client billing.
- An entry without a client or service can still record internal work, but it is not ready to become a priced invoice line item.
- Updating a service rate affects the rate used when work is added later; review historical entries and invoice amounts before billing.

## Add time to an invoice

1. Create or open a draft invoice for the same client.
2. Choose **Add from Time Tracking**.
3. Select the unbilled entries.
4. Review the generated descriptions, quantities, service rates, taxes, and total.
5. Save the invoice, then send it when ready.

Each selected time entry becomes a linked invoice line item. Once linked, Every treats the time as billed and prevents it from being deleted out from under the invoice.

<Tip>
  **Ask Every Agent:** "Create a draft invoice for ACME with all of this month's unbilled strategy time."
</Tip>

## Review and correct time

The Timesheet can be filtered by client, service, date range, and billed status. Open an unbilled entry to correct the client, service, time range, description, or private notes.

For billed time, correct the invoice relationship first. A source time record cannot be deleted while an invoice line item references it; this keeps the timesheet and client document from disagreeing.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can Every Agent start the live timer?">
    No. Use the timer widget for a running session. Every Agent can create a completed time entry when you provide a start/end time or duration.
  </Accordion>

  <Accordion title="Where does the hourly rate come from?">
    From the service linked to the time entry. Set or update service pricing under Services, then review the rate when the time becomes an invoice line item.
  </Accordion>

  <Accordion title="Can I invoice several time entries together?">
    Yes. Open a draft invoice for the client and select all relevant unbilled entries from Time Tracking. Each entry remains linked to the invoice for billed-status integrity.
  </Accordion>

  <Accordion title="Can I delete billed time?">
    Not while an invoice line item references it. Remove it from a draft invoice first. If the invoice has already been issued, preserve the source record and correct the client document through the invoice workflow.
  </Accordion>
</AccordionGroup>
