## Overview

The generally available Xero connection gives Every Agent conversational access to supported Xero accounting data and actions. Use it to answer questions, check records, prepare or update supported Xero objects, and bring accounting context into work you are doing in Every.

Xero remains the accounting system of record. Every remains the client-operations workspace for warm leads, proposals, invoices, payments, expenses, time tracking, and agent workflows.

<Note>
  Every also has a separate direct accounting-sync gateway in a limited pilot. Do not assume that connecting Xero on this page creates an automatic two-way sync or exposes pilot controls to your organization.
</Note>

## What Every Agent can do

The connected toolset includes reads such as:

- Organization details
- Contacts and contact groups
- Invoices, payments, and credit notes
- Bank transactions and accounts
- Items and tax rates
- Profit and loss, balance sheet, trial balance, aged receivables, and aged payables
- Tracking categories, quotes, timesheets, and selected payroll/leave data when available to the connected Xero user

It also includes supported Xero writes such as creating invoices, contacts, payments, bank transactions, credit notes, items, manual journals, quotes, tracking categories, and payroll timesheets, plus updating supported draft records.

Examples:

```text
Show me unpaid Xero invoices for Acme.
Pull the Xero profit and loss report for last quarter.
List recent bank transactions in Xero.
What tax rates are configured in my Xero organization?
Compare overdue invoices in Every with aged receivables in Xero.
Create a draft Xero invoice for Acme using account code 200.
```

The exact result depends on the connected Xero organization, your Xero role, the status of the target record, and the tools exposed by the current Xero connector.

<Warning>
  Xero writes change the accounting system of record. Use them in interactive chat and review Every's permission step carefully. Scheduled and unattended agent runs are limited to the reviewed read-only Xero tools.
</Warning>

## Connect Xero

1. Open [**Agent Settings → Connections**](https://app.every.ai/agent/connections).
2. Find Xero and choose **Connect**.
3. Sign in to Xero.
4. Select the Xero organization you intend to use.
5. Review the permissions Xero shows.
6. Return to Every and test with a read such as "List my recent Xero invoices."

<Warning>
  Confirm you connected the correct Xero organization before asking questions that may influence billing or financial decisions.
</Warning>

## Xero data and Every data are separate

An invoice in Xero is not automatically the same record as an invoice in Every. A Xero contact lookup—or a contact created in Xero—also does not create an Every client. Be explicit about the source in your request:

```text
Show overdue invoices in Xero.
Show overdue invoices in Every.
Use the Xero contact details as context while I create a draft client record in Every.
```

When you need records to live in Every, import or create them in Every and verify the result. When Xero should remain authoritative, use the Xero connection and name Xero explicitly in the request.

## Export Every invoices for Xero

You can export an accounting-ready CSV without using the live connection:

1. Open [**Data → Export Invoices**](https://app.every.ai/data/export-invoices).
2. Choose the Xero preset.
3. Set the date and status filters.
4. Preview and download the CSV.
5. Import it into Xero and review Xero's field mapping and validation results.

Xero imports normally create records in Xero's own workflow. Review them there before approval or sending.

## Migrating accounting history

Choose the path based on where the records should live:

- **Historical Every workspace:** Export CSV/XLSX from the source and use [**Data → Import**](https://app.every.ai/data/import). Review client matching, currencies, taxes, invoice status, line items, and payments before the write.
- **Xero stays authoritative:** Keep the data in Xero and use Every Agent for supported Xero reads and permission-gated actions.
- **Accounting-sync pilot:** If your organization has the Accounting settings feature, follow the controls and mapping requirements shown there. Do not infer pilot availability from this public connection guide.

## Disconnect or reconnect

Manage the connection under **Agent Settings → Connections**.

- Reconnect when Xero access is revoked, the organization changes, or the connection reports that authentication is required.
- Disconnecting removes Every Agent's Xero access; it does not delete records in Xero or Every.

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can Every Agent create or edit Xero records through this connection?">
    Yes, for the supported Xero object types and states. For example, it can create an invoice and update a draft invoice. Interactive writes use Every's permission flow; unattended runs are restricted to reviewed read-only Xero tools.
  </Accordion>

  <Accordion title="Does connecting Xero turn Every into a general ledger?">
    No. Xero remains the ledger, reconciliation, payroll, and accounting system. Every uses its own operational records for CRM, proposals, invoicing, payments, expenses, time, and pipeline workflows.
  </Accordion>

  <Accordion title="Will disconnecting Xero delete anything?">
    No. It removes the agent's access token and Xero capabilities. Existing records remain in their original systems.
  </Accordion>

  <Accordion title="Should I import my Xero data into Every?">
    Import only the history you want Every to operate on. If Xero should remain the source of truth, use the connection for lookups instead of creating a second unmanaged copy.
  </Accordion>
</AccordionGroup>

## Troubleshooting

**Xero not connected:** Reconnect under Agent Settings → Connections.

**Wrong organization:** Disconnect and connect again, selecting the intended Xero organization.

**A report is unavailable:** Check that the connected Xero user has access to that report and try a narrower period.

**Every and Xero totals differ:** Confirm that you are comparing the same dates, currencies, statuses, and record sets. The two systems do not automatically share one database.
